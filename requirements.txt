# PiScope Radar — pinned runtime dependencies.
#
# Frozen set, verified working on the production Pi (Python 3.11, armhf/aarch64).
# Pinning keeps deployments reproducible — `install.sh` installs from this file
# rather than unpinned package names, so an upstream release can't silently change
# behaviour between installs.
#
# To regenerate after a deliberate upgrade:
#   /opt/piscope/venv/bin/pip install -U <pkg> && /opt/piscope/venv/bin/pip freeze > requirements.txt
# then re-test on the Pi before committing.
#
# NOTE: starlette 1.3.1 (was 1.0.1) for CVE-2026-54283 — urlencoded form bodies
# ignored max_fields/max_part_size; reachable through /api/import's form parsing
# (5,000 fields: 1.0.1 parsed them all, 1.3.1 answers 400). Also covers 54282 /
# 48817 / 48818. fastapi 0.136.1 requires starlette>=0.46.0, so this is compatible.
#
# NOTE: anyio 4.14.2 (was 4.13.0) for CVE-2026-63374 / 64847 (TLS IDNA-2003
# encoding, process-pool stderr deadlock). Neither upgrade adds dependencies.
#
# NOTE: python-multipart is pinned to 0.0.32 (was 0.0.29) for CVE-2026-53537/53538/
# 53539/53540 — 53539 is a quadratic urlencoded-form parse that blocked the event
# loop ~1 s per 512 KiB body, reachable pre-auth through /api/import's form parsing.
